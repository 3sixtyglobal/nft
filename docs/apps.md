# NFT Applications

## nft-cli

This app provides a command line workflow for minting, resolving, transferring, and burning NFTs, alongside related wallet and faucet commands used in local and test environments. It is aimed at developers and operators who need repeatable terminal-driven interaction with the repository packages.
